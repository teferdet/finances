# Сервіси

Директорія `app/services/` містить бізнес-логіку, міграції бази даних, центральні оркестратори парсингу, UI-сервіси та `asyncio` фонові задачі, що працюють паралельно з Telegram-ботом.

Ці задачі взаємодіють з MongoDB та зовнішніми фінансовими API, використовуючи глобально впроваджений екземпляр `Bot` для доставки повідомлень при необхідності.

## Фонові сервіси та оркестрація

### `parser_service.py` (`CentralParserService`)
Центральний оркестратор для всіх операцій отримання цін та конвертації валют. Містить фонову задачу `run_parser_loop()` та потокобезпечну логіку парсингу.
- **Початкове заповнення**: Автоматично завантажує критичні списки валют при старті, якщо колекції БД порожні.
- **Годинний цикл фіату**: Перевіряє критичні фіатні валюти (`USD`, `EUR`, `UAH` тощо) проти 1-годинного TTL, запускаючи scraping через `fiat_parser.fetch_rates()` (з обходом Cloudflare).
- **3-годинний ринковий цикл**: Оновлює ціни крипто та акцій через API CoinMarketCap та Yahoo Finance.
- **Двигун конвертації**: `convert_currencies()` забезпечує швидкі, мульти-парні on-demand обчислення конвертації для `exchange.py`, `inline_query.py`, `group_admin.py` та `guest.py`.

### `alert_service.py`
Обробляє два автоматизовані фонові цикли:
1. **Перевірка алертів**: Запускається кожні 60 секунд (`run_alert_checker`). Порівнює неспрацьовані алерти з `current_prices`. Використовує пакетну розсилку (`_send_batched`) з урахуванням rate limit-ів Telegram.
2. **Моніторинг волатильності**: Запускається кожні 5 хвилин (`run_volatility_monitor`). Робить знімки цін щогодини та алертить користувачів при різких коливаннях цін, що перевищують їхній `volatility_threshold_pct` (за замовчуванням 5%).

### `ephemeral_service.py`
Забезпечує управління життєвим циклом повідомлень з автовидаленням (`send_ephemeral_or_fallback`, `edit_ephemeral_or_fallback`, `delete_ephemeral_or_fallback`).
- Активно використовується в групових чатах (`/group_settings`, `/rate`) для автовидалення тимчасових меню після налаштовуваного таймауту.

### `analytics_reporter.py`
Генерує комплексні метрики використання та аналітику здоров'я для адмінів груп і системних адмінів:
- Агрегує щоденний об'єм запитів конвертації, популярні валютні пари, активність груп та метрики спільнот.

### `digest_service.py`
- **Щотижневий дайджест**: Перевіряє умови кожні 30 хвилин, спрацьовує в неділю о 10:00 UTC. Компілює звіт P&L портфелів за 7 днів та розсилає локалізовані дайджести.

### `backup.py`
- Запускається щодня о 03:00 UTC (`run_daily_backup_loop`). Експортує дані MongoDB в JSON, стискає в `gzip` та зберігає в `backups/backup_YYYYMMDD_HHMMSS.gz`, підтримуючи ротацію з 7 останніх бекапів.

## Сервіси даних та зовнішніх інтеграцій

### `crypto_parser.py`
- Використовує `aiohttp` для отримання лістингів з API `CoinMarketCap`, заповнюючи `Crypto&Stocks` та оновлюючи `current_prices`.

### `stocks_parser.py`
- Обгортає `yfinance` в `asyncio.to_thread` / `run_in_executor` для запобігання блокування async-циклу при отриманні даних тікерів акцій.

### `fiat_parser.py`
- Використовує `curl_cffi` з імітацією браузера Chrome (`chrome120`) для обходу Cloudflare-захисту на `fx-rate.net`.

### `exchange_sync.py`
- **Підтримувані біржі**: Binance, Bybit.
- Синхронізує баланси API бірж з використанням підписаних `HMAC-SHA256` запитів та асинхронно оновлює лоти портфеля користувача.

### `portfolio_service.py`
- Обробляє CRUD-операції портфеля, трекінг лотів та серверну агрегацію для розрахунків загального P&L (`get_portfolio_with_pnl`).

### `security.py`
- Забезпечує симетричне шифрування Fernet (`cryptography.fernet`) для API-секретів користувачів у MongoDB. Ключ шифрування зберігається в `settings.security.fernet_key`.

### `export_service.py`
- Генерує статистику БД та CSV/Markdown-звіти для системних адміністраторів.

### `error_tracking.py`
- Відстежує здоров'я краулерів даних у `ProblematicSources` та звітує про збої зовнішніх API (CoinMarketCap, Yahoo Finance, fx-rate.net).

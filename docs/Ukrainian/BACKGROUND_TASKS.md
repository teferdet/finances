# Фонові задачі

Бот активно використовує asyncio для запуску паралельних фонових задач у основному процесі. Опціональний шар Redis забезпечує спільне кешування, але не є обов'язковим — бот переходить на in-memory кеш, якщо Redis недоступний.

Задачі завантажуються в `app/__main__.py` безпосередньо перед початком polling `aiogram` Dispatcher. Вони збираються в `asyncio.TaskGroup` або окремі посилання `asyncio.create_task()` та грацільно скасовуються при отриманні сигналу зупинки (SIGINT/SIGTERM).

## 1. Центральний оркестратор парсера (`CentralParserService`)
**Файл:** `app/services/parser_service.py` → `run_parser_loop()`

- **Початковий запуск:** Перевіряє MongoDB на наявність критичних валют. Якщо відсутні або неповні, виконує негайне початкове заповнення по фіат, крипто та акціях.
- **Годинний цикл фіату:** Перевіряє критичні фіатні валюти (`USD`, `EUR`, `UAH`, `PLN`, `CZK`, `GBP`, `CHF`, `CNY`, `JPY`, `CAD`, `AUD` тощо) проти 1-годинного TTL, запускаючи scraping через `fiat_parser.fetch_rates()` (з обходом Cloudflare через `curl_cffi`).
- **3-годинний ринковий цикл:** Оновлює ціни крипто та акцій через API CoinMarketCap та Yahoo Finance, оновлюючи як legacy-списки, так і плоский кеш `current_prices`.
- **Налаштовувані інтервали:** `parser.update_interval_sec` (фіат, за замовчуванням 3600с) та `parser.crypto_stocks_interval_sec` (крипто/акції, за замовчуванням 10800с).

## 2. Перевірка алертів
**Файл:** `app/services/alert_service.py` → `run_alert_checker()`

- **Інтервал:** Запускається кожні 60 секунд.
- **Дія:** Витягує неспрацьовані алерти з MongoDB (`triggered=False`). Оцінює актуальні ціни з `current_prices`. При збігу умов (`above`/`below`) конструює локалізоване повідомлення через `I18n` та розсилає з контролем швидкості.

## 3. Моніторинг волатильності
**Файл:** `app/services/alert_service.py` → `run_volatility_monitor()`

- **Знімки:** Наприкінці кожного циклу парсера, `save_price_snapshot()` зберігає словник цін у `price_history`.
- **Інтервал:** Запускається кожні 5 хвилин.
- **Дія:** Порівнює `current_prices` зі знімком годинної давності. Якщо дельта ціни активу перевищує поріг (≥ 3%), шукає активні портфелі з цим активом та алертить користувачів, що перевищили свій `volatility_threshold_pct`.

## 4. Щотижневий дайджест портфеля
**Файл:** `app/services/digest_service.py` → `run_digest_scheduler()`

- **Інтервал:** Перевіряє умови кожні 30 хвилин.
- **Дія:** Спрацьовує о 10:00 UTC щонеділі (`DIGEST_DAY = 6`). Витягує 7-денний знімок цін, компілює підсумки тижневого P&L для власників портфелів та розсилає локалізовані дайджести.

## 5. Очищення ephemeral-повідомлень
**Файл:** `app/utils/ephemeral.py` / `app/services/ephemeral_service.py`

- **Тригер:** Планується після UI-дій у групових чатах (`/group_settings`).
- **Дія:** Відстежує тимчасові ID повідомлень меню та автоматично видаляє їх після налаштованого таймауту (напр. 60–300с), підтримуючи чистоту історії групових чатів.

## 6. Локальні бекапи MongoDB
**Файл:** `app/services/backup.py` → `run_daily_backup_loop()`

- **Інтервал:** Запускається щодня о 03:00 UTC.
- **Дія:** Експортує колекції БД у JSON, стискає в `.gz` архіви у `backups/backup_YYYYMMDD_HHMMSS.gz` та очищує бекапи старші 7 днів.
- **Умова:** Запускається лише коли `bot.backup_enabled` = `True` у `settings.json`.

## 7. Аналітичний репортер
**Файл:** `app/services/analytics_reporter.py` → `AnalyticsReporter.start()`

- **Дія:** Фонова агрегація метрик активності користувачів — щоденні об'єми конвертацій, популярні валютні пари, активна участь груп та активність спільнот. Дані споживаються дашбордом `/admin` та веб-Dashboard API.

## 8. Ініціалізація Redis
**Файл:** `app/redis_client.py` → `init_redis()`

- **Запуск:** Намагається підключитися до Redis за URL з `settings.redis.url`. Якщо Redis недоступний або не сконфігурований, всі операції кешування прозоро переходять на in-process `MemoryCache`.
- **Операції:** `redis_get()`, `redis_set()`, `redis_delete()` — async-обгортки, що працюють ідентично незалежно від бекенду.

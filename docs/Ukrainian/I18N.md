# 🌐 Локалізація (i18n)

**Коротко:** Finances використовує легкий, кастомний движок інтернаціоналізації на базі JSON, розташований у `app/i18n.py`. Підтримує вкладені ключі, перемикання мови в реальному часі, форматування параметрів та автоматичний fallback на англійську.

## Структура JSON-локалей
Переклади зберігаються в директорії `locales/`. Движок використовує крапкову нотацію для парсингу вкладених ключів.

Приклад `locales/en.json`:
```json
{
  "menu": {
    "welcome": "Hello, {name}!",
    "settings": "⚙️ Settings"
  },
  "errors": {
    "not_found": "Data not found."
  }
}
```

## Підтримувані мови

| Код | Мова |
|---|---|
| `en` | Англійська |
| `uk` | Українська |
| `pl` | Польська |
| `cs` | Чеська |
| `sk` | Словацька |
| `de` | Німецька |
| `fr` | Французька |

Еталонний файл — `locales/en.json` — усі інші мовні файли повинні містити ту ж структуру ключів.

## Додавання нової мови

1. **Копіювання**: Скопіюйте `locales/en.json` у `locales/КОД_МОВИ.json` (напр., `es.json`).
2. **Переклад**: Перекладіть значення (праву частину), зберігаючи ключі без змін. Залиште плейсхолдери на кшталт `{name}` без змін.
3. **Реєстрація**: Додайте новий код мови (`"es"`) до `supported_languages` у `config/settings.json`.
4. **Валідація**: CI workflow `locales.yml` автоматично перевіряє, що всі мовні файли містять кожен ключ з `en.json`.

## Використання в обробниках

`I18nMiddleware` впроваджує локалізований екземпляр `i18n` та рядок `lang` у дані обробника:

```python
from aiogram.types import Message
from app.i18n import I18n

async def start_handler(message: Message, i18n: I18n, lang: str):
    text = i18n.get("menu.welcome", lang, name=message.from_user.first_name)
    await message.answer(text)
```

### `I18n.get(key, lang, **kwargs)`
- Розв'язує ключі розділені крапкою (напр., `"menu.welcome"`)
- Застосовує `str.format()` з переданими keyword-аргументами
- Fallback на англійську (`en`), якщо ключ не знайдено в цільовій мові
- Повертає сирий рядок ключа, якщо не знайдено в жодній мові

### `I18n.get_section(section, lang)`
- Повертає цілу секцію як словник (напр., `i18n.get_section("menu", "uk")`)

## Конвеєр Middleware

`I18nMiddleware` (зареєстрований як outer middleware на типах оновлень `message`, `callback_query`, `inline_query`, `my_chat_member` та `chat_member`) визначає мовне вподобання користувача з:
1. Запису користувача в БД (поле `Language`)
2. Перевизначення налаштувань групи (для групових чатів)
3. Мовного коду клієнта Telegram (`message.from_user.language_code`)
4. Мови за замовчуванням з `settings.i18n.default_language` (fallback: `en`)

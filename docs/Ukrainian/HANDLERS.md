# Обробники

Обробники визначають основний цикл взаємодії з користувачами та групами у Telegram-боті. Бот `teferdet/finances` використовує роутери `aiogram 3.x` для розділення відповідальностей. Кожен файл експортує екземпляр `router`, який реєструється централізовано в `bot.py`.

## Порядок реєстрації роутерів

Порядок реєстрації в `bot.py` (перший збіг виграє):

```
start → admin_groups → admin → language → crypto → stocks → settings
→ portfolio → exchange_api → alerts → my_data → portability → exchange
→ guest → [group_admin → groups] → [inline_query]
```

Роутери в дужках реєструються умовно залежно від feature-прапорців (`features.groups_enabled`, `features.inline_mode_enabled`).

## Директорія: `app/handlers/`

### 1. `start.py`
**Тригер**: `/start`, `/help`, `/donate`, `/privacy`, `/expense_manager`.
- **Потік**: Реєструє нових користувачів при `/start` та надсилає локалізовані привітальні повідомлення з reply-клавіатурою.

### 2. `admin.py`
**Тригер**: `/admin`, `/broadcast` або специфічні адмін-callback-и (`cb_admin_*`).
- **Доступ**: Обмежений через `_is_admin()`, який перевіряє список `admin_ids` з `settings.json` та динамічно оновлювану колекцію `Settings` у MongoDB.
- **Команди**:
  - `/admin`: Відображає адмін-дашборд.
  - `/broadcast`: Запускає FSM-потік (`BroadcastStates`) для розсилки повідомлення всім користувачам. Включає попередній перегляд і підтвердження.
- **Функції**: Діагностичні звіти (через `export_service.py`), перемикання режиму обслуговування, динамічне додавання/видалення адмінів, перевірка здоров'я парсера, CSV-звіти.

### 3. `admin_groups.py`
**Тригер**: Адмін-callback-и з префіксом `admin_groups:`.
- **Потік**: Надає глобальним системним адміністраторам глибокий моніторинг і контроль над зареєстрованими групами Telegram та Bot API 10.2 Communities.
- **Функції**: Списки статусів груп, ручна деактивація груп, зв'язування спільнот, огляд аналітики по групах.

### 4. `alerts.py`
**Тригер**: `/alert` та `alert_*` callback-и.
- **Потік**: Надає інтерфейс для встановлення цінових повідомлень для пар крипто, акцій або фіат.
- **Взаємодія з БД**: Зберігає неспрацьовані алерти в колекції `Alerts`.
- **Волатильність**: Дозволяє користувачам налаштувати `volatility_threshold_pct` (напр., 5% падіння).

### 5. `crypto.py`
**Тригер**: Команда `/crypto`.
- **Потік**: Отримує актуальні курси крипто з кешу MongoDB (розпарсені `crypto_parser.py`).
- **Відповідь**: Форматує топ-активи відповідно до конфігурації користувача.

### 6. `exchange.py` та `exchange_api.py`
**Тригер**: Callback-и для синхронізації бірж (напр., Binance, Bybit).
- **Потік**:
  - `exchange.py`: Catch-all обробник для приватних чатів для конвертації валют. Делегує до `parser_service.convert_currencies()` та використовує систему анімації `sendMessageDraft`.
  - `exchange_api.py`: Обробляє процес прив'язки API-ключів через FSM-введення `api_key` та `api_secret`. Взаємодіє з `exchange_sync.py` для шифрування секретів через `security.py` та синхронізує баланси бірж у портфель користувача.

### 7. `group_admin.py`
**Тригер**: `/group_settings`, `/rate`, `/group_stats` та `grp_settings:` callback-и.
- **Потік**: Дозволяє реальним адмінам груп керувати налаштуваннями валют, мовними вподобаннями та параметрами прослуховування.
- **Безпека та UX**:
  - Валідує дозволи групи через `is_chat_admin()`.
  - Безпечно обробляє `GroupAnonymousBot` Telegram, пропонуючи анонімним адмінам переключити профіль.
  - Використовує `ephemeral_service` для чистих повідомлень з автовидаленням у групових чатах.

### 8. `groups.py`
**Тригер**: Події `my_chat_member` (бот доданий/вилучений) або `/config` у групі.
- **Потік**: Виявляє коли бот додано або видалено з групового чату. Автоматично реєструє або оновлює статус групи в `app/repositories/groups.py` та пропонує deep-link для налаштування.

### 9. `guest.py` (Bot API 10.0+)
**Тригер**: Оновлення `guest_message` (`F.guest_query_id`).
- **Потік**: Обробляє згадки `@bot` у чатах, де бот НЕ є учасником. Парсить текст з фінансовими даними та відповідає через `message.answer_guest_query()` з `InlineQueryResultArticle`.

### 10. `inline_query.py`
**Тригер**: Введення `@fStatisticsBot <запит>` у будь-якому чаті.
- **Потік**: Використовує `TextProcessing` для парсингу запиту (напр., `100 USD`). Обчислює конвертацію та повертає `InlineQueryResultArticle`.
- **Умовний**: Реєструється лише коли `features.inline_mode_enabled` = `True`.

### 11. `language.py`
**Тригер**: `/language`, `/lang` або callback-и налаштувань.
- **Потік**: Показує локалізовану inline-клавіатуру підтримуваних мов. Оновлює мовні вподобання в БД.

### 12. `my_data.py`
**Тригер**: Callback-и "Мої дані" з меню налаштувань.
- **Потік**: Генерує огляд профілю користувача, включаючи відстежувані активи, активні алерти та налаштування, з опцією скидання.

### 13. `portability.py`
**Тригер**: `/export`, `/import` або отримання `.csv` документа.
- **Потік**:
  - `export`: Генерує `portfolio_export.csv` з записами активів.
  - `import`: Використовує pandas (запускається в `asyncio.to_thread`) для читання CSV, валідації тікерів та додавання валідних активів.

### 14. `portfolio.py`
**Тригер**: `/portfolio` та `portfolio_*` callback-и.
- **Потік**: Керує записами портфеля (`/portfolio add crypto BTC 1.5 60000`). Агрегує P&L з використанням кешу `current_prices`.

### 15. `settings.py`
**Тригер**: `/settings` та callback-и меню.
- **Потік**: Багатосторінкове меню налаштувань з використанням `cache.py` для збереження стану навігації. Модифікує watchlist-и фіат, крипто, акцій, базову валюту та UI-перемикачі.

### 16. `stocks.py`
**Тригер**: Команда `/stocks`.
- **Потік**: Повертає поточні оцінки акцій на основі вподобань користувача, використовуючи значення з `stocks_parser.py`.

# 📚 Документація Finances

Ласкаво просимо до технічної документації проєкту Finances — асинхронного Telegram-бота з інтегрованою веб-панеллю адміністратора.

## Ядро бота

- **[Архітектура](ARCHITECTURE.md)**: Огляд системи, потік даних, парсер і фонові задачі.
- **[Модулі](MODULES.md)**: Структура директорій і довідник основних модулів.
- **[Обробники](HANDLERS.md)**: Детальний опис усіх обробників команд і callback-ів Telegram.
- **[Сервіси](SERVICES.md)**: Фонові задачі, парсери даних і бізнес-логіка.
- **[База даних](DATABASE.md)**: Колекції MongoDB, індекси та структури документів.
- **[Локалізація (I18N)](I18N.md)**: Система локалізації на базі JSON.
- **[Адмін-панель](ADMIN_PANEL.md)**: Модулі `/admin`, контроль доступу, система розсилок.
- **[Фонові задачі](BACKGROUND_TASKS.md)**: Парсер, алерти, волатильність, дайджест, бекапи.
- **[Довідник API](API_REFERENCE.md)**: Зовнішні API — Telegram, CoinMarketCap, Yahoo Finance, fx-rate.net, Binance, Bybit.

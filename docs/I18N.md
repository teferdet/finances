# Internationalization (i18n)

The `teferdet/finances` bot provides extensive multi-language support across private chats, group conversations, and guest queries. Its translation system does not rely on third-party libraries (like `gettext` or `Babel`) but implements a custom lightweight, JSON-backed loader located in `app/i18n.py`.

## Core Implementation: `app/i18n.py`

### `I18n` Class
A singleton-like class responsible for loading and resolving localized text.

- **Loading**:
  - Upon initialization, the class traverses the `locales/` directory and loads all `.json` files into an in-memory dictionary.
  - The default language is defined in `settings.json` (typically `en`).
  - Supported languages are cached in the `self.supported` list.

- **Resolution (`get` and `get_section`)**:
  - Translates nested JSON keys using dot-notation (e.g., `keyboard.settings.bot` or `group_settings.title`).
  - **Fallback Mechanism**: If a key does not exist in the requested language (e.g., `fr`), the resolver automatically falls back to the default language (`en`).
  - **Dynamic Formatting**: Accepts `**kwargs` and uses Python's `.format(**kwargs)` to inject dynamic data into strings (e.g., `{name}` or `{hello}`).

## Translation Files (`locales/*.json`)

The translations are stored as deeply nested JSON structures to maintain logical boundaries. Currently supported languages include English (`en`), Ukrainian (`uk`), Polish (`pl`), Czech (`cs`), Slovak (`sk`), German (`de`), and French (`fr`).

### Key Structures
An overview of the translation hierarchy in `en.json`:

- `"keyboard"`:
  - `"settings"`: Bot UI buttons (`bot`, `groups`, `fiat`, `crypto`).
  - `"help"`: UI buttons related to FAQ and support.
- `"group_settings"`: Prompts, inline buttons, and status texts for the `/group_settings` management UI.
- `"guest"`: Conversion headers and descriptions for Bot API 10.0+ guest query responses.
- `"time"`: Time-of-day greetings (`morning`, `day`, `evening`, `night`).
- `"menu"`: Start menus (private vs group). Values are stored as lists of strings and concatenated to handle newlines nicely in JSON.
- `"exchange rate"`: System messages handling loading states, API errors, or parsing failures.
- `"inline mode"`: Strings specifically used when the bot is queried in `inline` mode `@fStatisticsBot ...`.
- `"settings"`: The text prompts for the user settings menu flow.
- `"other"`:
  - `"donate"`: Links to Donatello/BuyMeACoffee.
  - `"help"`: The `/help` text guide.
  - `"privacy"`: The `/privacy` policy text.
- `"alerts"`: Comprehensive translations for the alert and volatility system (`above`, `below`, `target`).

## Adding a New Language

1. Add the language code to `settings.json` under `i18n.supported_languages` (e.g., `"es"`).
2. Create a new file `locales/es.json`.
3. Copy the structure of `locales/en.json` and translate the values.
4. Restart the bot or push to main. The GitHub Actions `locales.yml` workflow will automatically validate schema completeness, and `I18n` will pick up the new language dynamically.
